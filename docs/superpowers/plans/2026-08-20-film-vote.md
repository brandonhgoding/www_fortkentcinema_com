# Film Vote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a curated, single-choice public film vote at `/vote` that feeds a relaunched repertory slot, plus the email list it builds.

**Architecture:** Poll domain models (`Poll`, `PollOption`, `Vote`) live in the existing `cinema` app beside `Engagement`; the email list lives in a new, deliberately generic `audience` app so it can outlive this feature. The public page is a Django template view with an HTMX partial swap for casting, degrading to a plain form POST. Staff management follows the existing `dashboard` patterns (`StaffRequiredMixin`, HTMX partials, per-page CSS).

**Tech Stack:** Django 5.2, HTMX (already vendored at `static/js/htmx.min.js`), Alpine.js (already loaded), esbuild CSS bundling via `frontend/`, SQLite in dev / Postgres in prod.

**Spec:** `docs/superpowers/specs/2026-08-20-film-vote-design.md`

## Global Constraints

- **Python line length: 88** (`.flake8` `max-line-length = 88`, `extend-ignore = E203, W503`). Migrations are excluded from flake8.
- **Verification gates that actually run here: `flake8` and `python manage.py test`.** mypy cannot run in this project and black is configured but unapplied — do not claim either as verification.
- **Public CSS is bundled.** Never add a `<link>` tag to `templates/base.html`. Add the stylesheet to `static/css/` **and** register it in `frontend/styles/main.css` in cascade order, then run `npm run build` from `frontend/`.
- **Dashboard CSS is per-page.** Dashboard templates link their own stylesheet in `{% block head_extra %}` — the opposite of the public site.
- **Django's `{# #}` comment is single-line only.** Multi-line comments in templates must use `{% comment %}`; a multi-line `{# #}` leaks as literal page text and `web/tests/test_pages.py` guards against it.
- **Ballots are single-choice.** One vote, one film. Not ranked-choice, not multi-select.
- **At most one poll may have status `OPEN`** at any time.
- **Never resurrect an unsubscribed email address.**
- **Store hashed IPs, never raw**, on `Vote`. (`Subscriber.consent_ip` does store the raw IP — that is the CAN-SPAM consent record and is staff-only.)
- Public copy must not promise a sending cadence. The email ask says the theater will let you know what won; it never says "newsletter".

```python
import uuid
from typing import ClassVar

from django.db import models
from django.utils import timezone


class SubscriberStatus(models.TextChoices):
    ACTIVE = "ACTIVE", "Active"
    UNSUBSCRIBED = "UNSUBSCRIBED", "Unsubscribed"


class SubscriberManager(models.Manager):
    def record(
        self, email: str, source: str, ip: str | None = None
    ) -> tuple["Subscriber", bool]:
        """Idempotently record an opt-in.

        Returns (subscriber, created). An address that has previously
        unsubscribed is returned untouched — a later signup must never
        silently re-add someone who opted out.
        """
        email = (email or "").strip().lower()
        if not email:
            raise ValueError("email is required")

        existing = self.filter(email=email).first()
        if existing is not None:
            return existing, False

        return self.create(email=email, source=source, consent_ip=ip), True

    def active(self) -> models.QuerySet["Subscriber"]:
        return self.filter(status=SubscriberStatus.ACTIVE)


class Subscriber(models.Model):
    """A person who asked to hear from us.

    Deliberately generic: nothing here references films or polls. `source` is
    only a label, so the next feature that needs an email list reuses this
    model rather than growing its own.
    """

    objects: ClassVar[SubscriberManager] = SubscriberManager()

    email = models.EmailField(unique=True)
    status = models.CharField(
        max_length=20,
        choices=SubscriberStatus.choices,
        default=SubscriberStatus.ACTIVE,
    )
    source = models.CharField(
        max_length=32,
        help_text="Where the opt-in happened, e.g. 'poll_vote'.",
    )

    # Consent record. Kept because CAN-SPAM compliance means being able to
    # show when and from where someone opted in.
    consent_at = models.DateTimeField(auto_now_add=True)
    consent_ip = models.GenericIPAddressField(null=True, blank=True)

    # Generated from the first row even though nothing sends mail yet.
    # Retrofitting tokens onto an existing list is a migration worth avoiding.
    unsubscribe_token = models.UUIDField(
        default=uuid.uuid4, unique=True, editable=False
    )
    unsubscribed_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        ordering = ["-consent_at"]
        verbose_name = "Subscriber"
        verbose_name_plural = "Subscribers"

    def __str__(self) -> str:
        return self.email

    def save(self, *args, **kwargs) -> None:
        self.email = (self.email or "").strip().lower()
        super().save(*args, **kwargs)

    def unsubscribe(self) -> None:
        if self.status == SubscriberStatus.UNSUBSCRIBED:
            return
        self.status = SubscriberStatus.UNSUBSCRIBED
        self.unsubscribed_at = timezone.now()
        self.save(update_fields=["status", "unsubscribed_at"])
```

```python
from typing import Any, ClassVar

from django.db import models
from django.db.models import Manager
from django.urls import reverse
from django.utils.text import slugify

from .engagement import Engagement
from .film import Film


class PollStatus(models.TextChoices):
    DRAFT = "DRAFT", "Draft"
    OPEN = "OPEN", "Open"
    CLOSED = "CLOSED", "Closed"
    ANNOUNCED = "ANNOUNCED", "Announced"


class Poll(models.Model):
    """One round of audience voting on what we screen next.

    The ballot is curated: staff pick every option. That is what makes a
    stuffed ballot survivable — the winner is always a film we already
    approved for screening.
    """

    objects: ClassVar[Manager["Poll"]]

    title = models.CharField(max_length=200)
    slug = models.SlugField(max_length=200, unique=True, blank=True)
    blurb = models.TextField(
        blank=True, help_text="Shown above the ballot. One or two sentences."
    )

    opens_at = models.DateTimeField(null=True, blank=True)
    closes_at = models.DateTimeField(null=True, blank=True)

    status = models.CharField(
        max_length=20, choices=PollStatus.choices, default=PollStatus.DRAFT
    )
    results_visible = models.BooleanField(
        default=True,
        help_text="Show running tallies while voting is open. Off hides them "
        "until the round closes.",
    )

    winner = models.ForeignKey(
        "cinema.PollOption",
        null=True,
        blank=True,
        on_delete=models.SET_NULL,
        related_name="won_polls",
    )
    # The booking the winner became. This is what turns the results page from
    # "Casablanca won" into "Casablanca won, here are the showtimes".
    engagement = models.ForeignKey(
        Engagement,
        null=True,
        blank=True,
        on_delete=models.SET_NULL,
        related_name="polls",
    )

    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["-created_at"]
        constraints = [
            # The public page assumes a single live poll. Enforced in the
            # database so a dashboard bug cannot produce two.
            models.UniqueConstraint(
                fields=["status"],
                condition=models.Q(status="OPEN"),
                name="cinema_poll_only_one_open",
            )
        ]
        verbose_name = "Poll"
        verbose_name_plural = "Polls"

    def __str__(self) -> str:
        return self.title

    def get_absolute_url(self) -> str:
        return reverse("vote_archive", kwargs={"slug": self.slug})

    def generate_slug(self) -> str:
        base = slugify(self.title) or "poll"
        slug = base
        n = 2
        while Poll.objects.filter(slug=slug).exclude(pk=self.pk).exists():
            slug = f"{base}-{n}"
            n += 1
        return slug

    def save(self, *args: Any, **kwargs: Any) -> None:
        if not self.slug:
            self.slug = self.generate_slug()
        super().save(*args, **kwargs)

    @property
    def is_open(self) -> bool:
        return self.status == PollStatus.OPEN

    @property
    def total_votes(self) -> int:
        return self.votes.count()

    def tallies(self, by_rank: bool = False) -> list[dict]:
        """Per-option counts and whole-number percentages.

        Ballot order by default; `by_rank=True` sorts by descending count,
        which is what the results view and the announce step want.
        """
        total = self.total_votes
        rows = []
        for option in self.options.select_related("film").annotate(
            n=models.Count("votes")
        ):
            rows.append(
                {
                    "option": option,
                    "count": option.n,
                    "percent": round(option.n / total * 100) if total else 0,
                }
            )
        if by_rank:
            rows.sort(key=lambda r: r["count"], reverse=True)
        return rows


class PollOption(models.Model):
    """One film on a ballot.

    Points at a real `Film`, so a ballot reuses posters, runtimes and TMDB
    metadata we already have — building a round is picking films, not typing
    metadata.
    """

    objects: ClassVar[Manager["PollOption"]]

    poll = models.ForeignKey(Poll, on_delete=models.CASCADE, related_name="options")
    film = models.ForeignKey(
        Film, on_delete=models.PROTECT, related_name="poll_options"
    )
    blurb = models.CharField(
        max_length=280,
        blank=True,
        help_text="Optional pitch for this film. Falls back to the synopsis.",
    )
    sort_order = models.PositiveIntegerField(default=0)

    class Meta:
        ordering = ["sort_order", "id"]
        constraints = [
            models.UniqueConstraint(
                fields=["poll", "film"], name="cinema_polloption_unique_film_per_poll"
            )
        ]

    def __str__(self) -> str:
        return f"{self.film.title} ({self.poll.title})"

    @property
    def vote_count(self) -> int:
        return self.votes.count()

    @property
    def description(self) -> str:
        return self.blurb or self.film.description


class Vote(models.Model):
    """A single ballot cast.

    `voter_key` is a random token from a long-lived cookie. `ip_hash` is a
    salted hash — never the raw address — kept only so a flood from one
    connection is visible and cappable.
    """

    objects: ClassVar[Manager["Vote"]]

    poll = models.ForeignKey(Poll, on_delete=models.CASCADE, related_name="votes")
    option = models.ForeignKey(
        PollOption, on_delete=models.CASCADE, related_name="votes"
    )
    voter_key = models.CharField(max_length=36, db_index=True)
    ip_hash = models.CharField(max_length=64, blank=True, db_index=True)
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["-created_at"]
        constraints = [
            models.UniqueConstraint(
                fields=["poll", "voter_key"], name="cinema_vote_one_per_poll_per_voter"
            )
        ]

    def __str__(self) -> str:
        return f"{self.voter_key[:8]}… → {self.option.film.title}"
```

```python
"""Vote casting and its integrity rules.

The protection here is deliberately soft. A determined person can clear
cookies and vote again from a phone, and no CAPTCHA is used because the
friction would cost more real votes than the cheating costs us. The real
defense is the curated ballot: every option is a film we already approved,
so a stuffed ballot still returns something we are happy to screen.

What IS hard: a closed poll never accepts a write, and one browser gets one
vote per poll (a database constraint, see cinema/models/poll.py).
"""

import hashlib
import uuid

from django.conf import settings
from django.db import IntegrityError, transaction

from .models import PollStatus, Vote

VOTER_COOKIE = "fkc_voter"
VOTER_COOKIE_MAX_AGE = 60 * 60 * 24 * 365  # one year

# High enough that a family, the library, or UMFK's NAT are unaffected; low
# enough that scripting gets boring.
IP_VOTE_CAP = 5


class VoteError(Exception):
    """Base for every refusal to record a vote."""


class PollNotOpen(VoteError):
    pass


class AlreadyVoted(VoteError):
    pass


class IPCapReached(VoteError):
    pass


class OptionMismatch(VoteError):
    pass


def hash_ip(ip: str | None) -> str:
    """Salted hash of an address. We never store the raw value."""
    if not ip:
        return ""
    salted = f"{settings.SECRET_KEY}:{ip}".encode()
    return hashlib.sha256(salted).hexdigest()


def client_ip(request) -> str | None:
    forwarded = request.META.get("HTTP_X_FORWARDED_FOR", "")
    if forwarded:
        return forwarded.split(",")[0].strip() or None
    return request.META.get("REMOTE_ADDR") or None


def new_voter_key() -> str:
    return str(uuid.uuid4())


def voter_key_from(request) -> str | None:
    return request.COOKIES.get(VOTER_COOKIE) or None


def existing_vote(poll, voter_key: str | None) -> Vote | None:
    if not voter_key:
        return None
    return (
        Vote.objects.filter(poll=poll, voter_key=voter_key)
        .select_related("option", "option__film")
        .first()
    )


def cast_vote(poll, option, voter_key: str, ip: str | None = None) -> Vote:
    """Record one vote, or raise a VoteError subclass explaining the refusal."""
    if poll.status != PollStatus.OPEN:
        raise PollNotOpen(f"Poll {poll.pk} is {poll.status}, not open.")

    if option.poll_id != poll.pk:
        raise OptionMismatch("That option does not belong to this poll.")

    if Vote.objects.filter(poll=poll, voter_key=voter_key).exists():
        raise AlreadyVoted("This browser has already voted in this poll.")

    ip_hash = hash_ip(ip)
    if ip_hash:
        seen = Vote.objects.filter(poll=poll, ip_hash=ip_hash).count()
        if seen >= IP_VOTE_CAP:
            raise IPCapReached("Too many votes from this connection.")

    try:
        with transaction.atomic():
            return Vote.objects.create(
                poll=poll, option=option, voter_key=voter_key, ip_hash=ip_hash
            )
    except IntegrityError as exc:
        # Two concurrent requests from the same browser. The database
        # constraint is the authority; translate it into our own error.
        raise AlreadyVoted("This browser has already voted in this poll.") from exc
```

```python
"""Resolves what the /vote page should show.

Five states, all of which must render: no poll, an unvoted ballot, a cast
ballot, a closed round awaiting a decision, and an announced winner. This
lives here rather than in the view so each state is unit-testable without
going through HTTP, matching the cinema_data / showtimes convention.
"""

from django.db.models import QuerySet

from cinema.models import Poll, PollStatus
from cinema.voting import existing_vote

STATE_NO_POLL = "no_poll"
STATE_BALLOT = "ballot"
STATE_VOTED = "voted"
STATE_CLOSED = "closed"
STATE_ANNOUNCED = "announced"

_DECIDED = (PollStatus.CLOSED, PollStatus.ANNOUNCED)


def current_poll() -> Poll | None:
    """The single open poll, if there is one. At most one can exist."""
    return (
        Poll.objects.filter(status=PollStatus.OPEN)
        .select_related("winner", "engagement")
        .first()
    )


def latest_decided_poll() -> Poll | None:
    """The most recent round that has finished voting.

    Announced rounds outrank merely-closed ones, so a freshly closed round
    does not bury the winner people are still looking for.
    """
    announced = (
        Poll.objects.filter(status=PollStatus.ANNOUNCED)
        .select_related("winner", "winner__film", "engagement")
        .first()
    )
    if announced is not None:
        return announced
    return (
        Poll.objects.filter(status=PollStatus.CLOSED)
        .select_related("winner", "winner__film", "engagement")
        .first()
    )


def archived_polls() -> QuerySet:
    """Past rounds, newest first. There is no separate archive index page —
    /vote lists these and each links to its own /vote/<slug>."""
    return Poll.objects.filter(status__in=_DECIDED).select_related(
        "winner", "winner__film"
    )


def resolve_vote_page(voter_key: str | None, poll: Poll | None = None) -> dict:
    """Build the context for /vote or /vote/<slug>.

    `poll` pins the page to a specific round (the archive view). Without it,
    the open poll wins, falling back to the most recent decided round.
    """
    if poll is None:
        poll = current_poll() or latest_decided_poll()

    archive = archived_polls()
    if poll is not None:
        archive = archive.exclude(pk=poll.pk)

    ctx = {
        "state": STATE_NO_POLL,
        "poll": poll,
        "options": [],
        "tallies": [],
        "show_results": False,
        "voted_option": None,
        "archive": archive,
    }

    if poll is None:
        return ctx

    ctx["options"] = list(poll.options.select_related("film"))

    if poll.status == PollStatus.ANNOUNCED:
        ctx["state"] = STATE_ANNOUNCED
        ctx["show_results"] = True
        ctx["tallies"] = poll.tallies(by_rank=True)
        return ctx

    if poll.status == PollStatus.CLOSED:
        ctx["state"] = STATE_CLOSED
        ctx["show_results"] = poll.results_visible
        if poll.results_visible:
            ctx["tallies"] = poll.tallies(by_rank=True)
        return ctx

    if poll.status != PollStatus.OPEN:
        # A draft round is not public. Treat it as no poll at all.
        ctx["poll"] = None
        ctx["options"] = []
        return ctx

    vote = existing_vote(poll, voter_key)
    if vote is None:
        ctx["state"] = STATE_BALLOT
        return ctx

    ctx["state"] = STATE_VOTED
    ctx["voted_option"] = vote.option
    ctx["show_results"] = poll.results_visible
    if poll.results_visible:
        ctx["tallies"] = poll.tallies(by_rank=True)
    return ctx
```

```python
def _vote_context(request, poll=None, message=""):
    """Shared context for every rendering of the vote panel."""
    voter_key = vote_engine.voter_key_from(request) or request.vote_key
    ctx = vote_service.resolve_vote_page(voter_key=voter_key, poll=poll)
    ctx["message"] = message
    return ctx


def _with_voter_cookie(response, request):
    """Set the voter cookie when the browser does not already carry one.

    httpOnly: nothing in the page needs to read it, and it is the only thing
    standing between one browser and a second vote.
    """
    if not vote_engine.voter_key_from(request):
        response.set_cookie(
            vote_engine.VOTER_COOKIE,
            request.vote_key,
            max_age=vote_engine.VOTER_COOKIE_MAX_AGE,
            httponly=True,
            samesite="Lax",
            secure=not settings.DEBUG,
        )
    return response


class VoteView(View):
    """/vote — the canonical, stable URL for the current round.

    This is the link pasted into Facebook, so it must stay valid across every
    round. Past rounds move to /vote/<slug>; see VoteArchiveView.
    """

    def get(self, request):
        request.vote_key = (
            vote_engine.voter_key_from(request) or vote_engine.new_voter_key()
        )
        ctx = _vote_context(request)
        response = render(request, "web/vote.html", ctx)
        return _with_voter_cookie(response, request)


class VoteArchiveView(View):
    """/vote/<slug> — a specific round.

    While a round is open its slug URL redirects to /vote, so exactly one page
    collects the shares and links.
    """

    def get(self, request, slug):
        poll = get_object_or_404(Poll, slug=slug)
        if poll.status == PollStatus.OPEN:
            return redirect("vote")
        if poll.status == PollStatus.DRAFT:
            raise Http404("No such poll.")

        request.vote_key = (
            vote_engine.voter_key_from(request) or vote_engine.new_voter_key()
        )
        ctx = _vote_context(request, poll=poll)
        return render(request, "web/vote.html", ctx)


class VoteCastView(View):
    """POST /vote/cast — record one ballot.

    HTMX gets the swapped panel back; a plain form POST is redirected to /vote
    so a refresh cannot re-submit.
    """

    def post(self, request):
        request.vote_key = (
            vote_engine.voter_key_from(request) or vote_engine.new_voter_key()
        )

        poll = vote_service.current_poll()
        option_id = request.POST.get("option")
        if not option_id:
            return HttpResponseBadRequest("No option selected.")

        message = ""
        if poll is None:
            message = "Voting has closed for this round."
        else:
            option = poll.options.filter(pk=option_id).first()
            if option is None:
                return HttpResponseBadRequest("Unknown option.")
            try:
                vote_engine.cast_vote(
                    poll,
                    option,
                    request.vote_key,
                    ip=vote_engine.client_ip(request),
                )
            except vote_engine.AlreadyVoted:
                message = "You've already voted in this round."
            except vote_engine.PollNotOpen:
                message = "Voting has closed for this round."
            except vote_engine.IPCapReached:
                message = "We've had a lot of votes from this connection already."
            except vote_engine.OptionMismatch:
                return HttpResponseBadRequest("Unknown option.")

        if request.headers.get("HX-Request"):
            ctx = _vote_context(request, message=message)
            response = render(request, "partials/vote_panel.html", ctx)
            return _with_voter_cookie(response, request)

        response = redirect("vote")
        return _with_voter_cookie(response, request)
```

```python
"""Staff surface for audience polls.

Separate from dashboard/views.py, which is already long and shares no
helpers with this feature.
"""

import json

from django.http import HttpResponse
from django.shortcuts import get_object_or_404, render
from django.urls import reverse
from django.views import View

from cinema.models import Poll

from .forms import PollForm
from .mixins import StaffRequiredMixin


def _poll_list_response(request, toast_message: str = "") -> HttpResponse:
    response = render(
        request,
        "dashboard/_poll_list.html",
        {"polls": Poll.objects.all()},
    )
    if toast_message:
        response["HX-Trigger"] = json.dumps(
            {"dashboard-toast": {"kind": "success", "message": toast_message}}
        )
    return response


def _render_poll_form(request, form, action_url: str, submit_label: str):
    return render(
        request,
        "dashboard/_poll_form.html",
        {"form": form, "action_url": action_url, "submit_label": submit_label},
    )


class PollListView(StaffRequiredMixin, View):
    def get(self, request):
        return render(
            request, "dashboard/polls.html", {"polls": Poll.objects.all()}
        )


class PollCreateView(StaffRequiredMixin, View):
    def get(self, request):
        return _render_poll_form(
            request, PollForm(), reverse("dashboard:poll_create"), "Create Poll"
        )

    def post(self, request):
        form = PollForm(request.POST)
        if form.is_valid():
            form.save()
            return _poll_list_response(request, "Poll created")
        return _render_poll_form(
            request, form, reverse("dashboard:poll_create"), "Create Poll"
        )


class PollEditView(StaffRequiredMixin, View):
    def get(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        return _render_poll_form(
            request,
            PollForm(instance=poll),
            reverse("dashboard:poll_edit", args=[pk]),
            "Save Changes",
        )

    def post(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        form = PollForm(request.POST, instance=poll)
        if form.is_valid():
            form.save()
            return _poll_list_response(request, "Poll updated")
        return _render_poll_form(
            request,
            form,
            reverse("dashboard:poll_edit", args=[pk]),
            "Save Changes",
        )
```

```python
class PollOptionAddView(StaffRequiredMixin, View):
    """Add a film to a ballot.

    Refused once voting is open: changing the ballot mid-round would make the
    votes already cast meaningless.
    """

    def post(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        if poll.status != PollStatus.DRAFT:
            return HttpResponse(
                "The ballot is locked once a round leaves draft.", status=409
            )

        film = Film.objects.filter(pk=request.POST.get("film_id")).first()
        if film is None:
            return HttpResponseBadRequest("Unknown film.")

        if not poll.options.filter(film=film).exists():
            highest = poll.options.count()
            PollOption.objects.create(poll=poll, film=film, sort_order=highest + 1)

        return _poll_options_response(request, poll, f"Added {film.title}")


class PollOptionRemoveView(StaffRequiredMixin, View):
    def post(self, request, pk, option_pk):
        poll = get_object_or_404(Poll, pk=pk)
        if poll.status != PollStatus.DRAFT:
            return HttpResponse(
                "The ballot is locked once a round leaves draft.", status=409
            )
        poll.options.filter(pk=option_pk).delete()
        return _poll_options_response(request, poll, "Removed from ballot")


class PollOptionMoveView(StaffRequiredMixin, View):
    """Reorder the ballot by swapping an option with its neighbour.

    Ballot order is what visitors see top to bottom, so it is worth
    controlling. Locked once voting opens, like the rest of the ballot.
    """

    def post(self, request, pk, option_pk):
        poll = get_object_or_404(Poll, pk=pk)
        if poll.status != PollStatus.DRAFT:
            return HttpResponse(
                "The ballot is locked once a round leaves draft.", status=409
            )

        direction = request.POST.get("direction")
        if direction not in ("up", "down"):
            return HttpResponseBadRequest("Direction must be 'up' or 'down'.")

        options = list(poll.options.all())
        index = next(
            (i for i, opt in enumerate(options) if opt.pk == option_pk), None
        )
        if index is None:
            return HttpResponseBadRequest("Unknown option.")

        target = index - 1 if direction == "up" else index + 1
        if 0 <= target < len(options):
            options[index], options[target] = options[target], options[index]
            # Renumber the whole ballot: sort_order values arrive from adds and
            # earlier swaps, so a bare pairwise swap can leave duplicates.
            for position, option in enumerate(options, start=1):
                if option.sort_order != position:
                    option.sort_order = position
                    option.save(update_fields=["sort_order"])

        return _poll_options_response(request, poll)
```

```python
_ALLOWED_STATUSES = {
    PollStatus.DRAFT,
    PollStatus.OPEN,
    PollStatus.CLOSED,
    PollStatus.ANNOUNCED,
}


class PollStatusView(StaffRequiredMixin, View):
    """Move a round through draft -> open -> closed.

    Refuses a second open poll with a plain message rather than letting the
    database constraint surface as a 500: the public page assumes exactly one
    live round, so this is a mistake worth naming.
    """

    def post(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        status = request.POST.get("status")
        if status not in _ALLOWED_STATUSES:
            return HttpResponseBadRequest("Unknown status.")

        if status == PollStatus.OPEN:
            if not poll.options.exists():
                return HttpResponse(
                    "Add films to the ballot before opening the round.", status=409
                )
            others = Poll.objects.filter(status=PollStatus.OPEN).exclude(pk=poll.pk)
            if others.exists():
                return HttpResponse(
                    f"“{others.first().title}” is already open. Close it first.",
                    status=409,
                )

        poll.status = status
        poll.save(update_fields=["status"])
        return _poll_status_response(request, poll, f"Poll {status.lower()}")


def _poll_status_response(request, poll, toast_message: str = "") -> HttpResponse:
    response = render(request, "dashboard/_poll_status.html", {"poll": poll})
    if toast_message:
        response["HX-Trigger"] = json.dumps(
            {"dashboard-toast": {"kind": "success", "message": toast_message}}
        )
    return response


class PollAnnounceView(StaffRequiredMixin, View):
    """Name the winner and, once booked, attach the engagement.

    The engagement link is what turns the public results page from
    "Casablanca won" into "Casablanca won, here are the showtimes".
    """

    def get(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        return render(
            request,
            "dashboard/_poll_announce.html",
            {
                "poll": poll,
                "tallies": poll.tallies(by_rank=True),
                "engagements": Engagement.objects.order_by("-start_date")[:20],
            },
        )

    def post(self, request, pk):
        poll = get_object_or_404(Poll, pk=pk)
        if poll.status == PollStatus.OPEN:
            return HttpResponse(
                "Close the round before announcing a winner.", status=409
            )

        winner = poll.options.filter(pk=request.POST.get("winner")).first()
        if winner is None:
            return HttpResponseBadRequest("Unknown option.")

        poll.winner = winner
        poll.status = PollStatus.ANNOUNCED

        engagement_id = request.POST.get("engagement")
        if engagement_id:
            poll.engagement = Engagement.objects.filter(pk=engagement_id).first()

        poll.save(update_fields=["winner", "status", "engagement"])
        return _poll_status_response(request, poll, "Winner announced")
```

```python
"""Staff surface for the email list.

Nothing in this project sends mail yet, so the CSV export IS the delivery
mechanism: close a round, export, paste into Square Marketing. Unsubscribes
are filtered here rather than only in the database, so an opt-out cannot
leak into a send.
"""

import csv

from django.http import HttpResponse
from django.shortcuts import render
from django.views import View

from audience.models import Subscriber

from .mixins import StaffRequiredMixin


class SubscriberListView(StaffRequiredMixin, View):
    def get(self, request):
        subscribers = Subscriber.objects.all()
        return render(
            request,
            "dashboard/subscribers.html",
            {
                "subscribers": subscribers,
                "active_count": Subscriber.objects.active().count(),
            },
        )


class SubscriberExportView(StaffRequiredMixin, View):
    def get(self, request):
        response = HttpResponse(content_type="text/csv")
        response["Content-Disposition"] = (
            'attachment; filename="subscribers.csv"'
        )

        writer = csv.writer(response)
        writer.writerow(["email", "source", "consent_at"])
        for sub in Subscriber.objects.active().order_by("consent_at"):
            writer.writerow(
                [sub.email, sub.source, sub.consent_at.isoformat()]
            )
        return response
```
